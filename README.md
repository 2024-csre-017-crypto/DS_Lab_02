  Lab 02: Lists & Linked Lists
  
🔹 Introduction
This lab focuses on different types of list data structures in C++ and how they are implemented. It covers arrays, singly linked lists, doubly linked lists, and circular linked lists, ending with a practical application: the Josephus Problem.
The lab is designed to help understand the differences between these structures, how to perform insertion and deletion, and where each type is most useful.

🔹 Objectives
Practice basic list operations using arrays.
Implement and manipulate singly linked lists.
Understand and code doubly linked lists.
Apply circular linked lists to solve the Josephus problem.

🔹 Lab Contents

🔸 Part A – Lists with Arrays
Insert into Array → requires shifting elements right.
Delete from Array → requires shifting elements left.

🔸 Part B – Singly Linked List
Create & Traverse → each node has data and next.
Insert & Delete → insert at head, delete head, and update pointers.

🔸 Part C – Doubly Linked List
Each node has next and prev.
Allows forward and backward traversal.

🔸 Part D – Circular Linked List & Josephus Problem
Circular Traversal → last node connects back to head.
Josephus Problem → simulate elimination of every M-th person until one remains (a classic example of circular lists).


🔹 Key Learnings
Arrays have fixed size and need shifting for insert/delete.
Singly Linked Lists allow dynamic size and easier node insertion/deletion.
Doubly Linked Lists support bidirectional traversal.
Circular Linked Lists are useful in games, scheduling, and simulations (e.g., Josephus Problem).

🔹 Wrap-up
This lab strengthens understanding of linear and circular data structures. By the end, you should be able to:
Differentiate between array-based and pointer-based lists.
Implement singly, doubly, and circular linked lists.

Use circular lists to solve problems like Josephus.
